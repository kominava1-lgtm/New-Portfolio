# Santiago C. Navato II — Portfolio

A responsive personal portfolio website for Santiago C. Navato II, a Computer Engineering graduate and aspiring frontend developer based in Pangasinan, Philippines.

The site introduces who is the developer, highlights project placeholders, presents education and skills, and provides contact and social links.

## Built with

- HTML5
- CSS3
- Google Fonts (Space Grotesk, Inter, and JetBrains Mono)

## Getting started

No build tools or dependencies are required.

1. Clone or download this repository.
2. Open `main.html` in any modern web browser.

For a smoother local-development experience, serve the folder with an editor extension such as VS Code Live Server.

## Project structure

```text
.
├── main.html                       # Portfolio page markup
├── style-new.css                   # Active stylesheet
├── style.css                       # Earlier/alternate stylesheet
├── IMG_9546.JPG                    # Profile photograph
├── bg2.jpg                         # Project card image
├── bg3.png                         # Project card image
└── CV-Navato, Santiago II Cosas.pdf # Resume/CV
```

## Customization

- Replace the placeholder project cards in `main.html` with real project names, descriptions, tags, screenshots, and destination links.
- Update contact details and social links as needed.
- Adjust colors, layout, typography, and responsive behavior in `style-new.css`.
- Keep linked assets in the project root, or update their paths in `main.html` if you move them.
